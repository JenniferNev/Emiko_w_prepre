# Chemistry lab world (`world/scisci`)

## Goal

A lab with periodic-table elements as grabbable spheres. Each sphere shows its element's color and symbol and bonds in chemically correct directions.

- Bonded atoms form compounds that can be **named, renamed and saved**.
- Saved compounds appear on a second table and can be grabbed from there.
- **Originals stay:** grabbing an element or compound from a table spawns a replacement in its place.
- **Deleting:** any held atom or compound can be deleted.
- **Clear Chemicals button:** removes every spawned atom and compound, but keeps the originals on the tables.

**First version:** single bonds, a few elements, local only (bonds synced in Phase 5).

## Scene layout

- **`ChemistryLab`:** an empty object at (3, 0, 12) that holds everything in the lab.
  - Scale it **uniformly** (the same value on X, Y and Z) to resize the whole lab. This keeps the proportions between elements correct.
  - Atoms read their size from their real (world) scale, so bond lengths scale with the group.
- **`Table`:** child of `ChemistryLab`, made from `Blender/LabTable.blend` and exported as `Assets/Models/Table.fbx`. It has a Box Collider and is Static (the group itself is **not** Static).
- **Atoms:** under `ChemistryLab`, **not** Static. They have VRC Pickup, and a Rigidbody with **Is Kinematic ✓** and **Use Gravity ✗**, so they float where you let go.

## Element data: `Assets/ChemistryLab/Data/elements.json`

This file has all 118 elements. It's generated by `Tools/elements/build_elements.py`, so don't edit the JSON by hand. To regenerate it:

```
python3 Tools/elements/build_elements.py
```

### Sources

| Property | Source |
|---|---|
| Colors | **Jmol CPK colors**, the standard in molecular viewers, PubChem and most textbook figures (carbon is grey `#909090`). Jmol defines colors for elements 1–109; elements 110–118 have no standard color and use Jmol's "unknown" color. |
| Covalent radii | **Cordero et al. 2008**, "Covalent radii revisited", *Dalton Trans.* 2832, doi:10.1039/b801115j (elements 1–96). **Pyykkö & Atsumi 2009** for elements 97–118, plus double- and triple-bond radii. |
| Other properties | **PubChem** (NIH): mass, Pauling electronegativity, oxidation states, van der Waals radii, category |
| Bond angles | **NIST CCCBDB** measured geometries: H₂O 104.48°, NH₃ 106.67°, CH₄ 109.471°, H₂S 92.11°, PH₃ 93.3°. Elsewhere, ideal VSEPR angles. |

### Size rule

The scale is **1 pm = 1 mm**, and each sphere's diameter is 2 × its covalent radius. Two bonded atoms then **touch at the real bond length** (r₁ + r₂). Checked against NIST measurements:

| Bond | r₁ + r₂ (Cordero) | Measured (NIST) |
|---|---|---|
| C–H | 107 pm | 108.7 pm |
| O–H | 97 pm | 95.8 pm |
| N–H | 102 pm | 101.2 pm |

## Shaders: `Assets/ChemistryLab/Shaders/`

### `ChemistryLab/Atom Unlit` (the sphere)
- Flat element color that **ignores world lighting**.
- Optional rim darkening based on viewing angle, so the ball still looks round. Set **Rim Darkening** to 0 for completely flat color.
- Casts shadows but doesn't receive them.

### `ChemistryLab/Atom Symbol` (the letter)
Used on a TextMeshPro **3D** text object called `Symbol`, a child of the atom.
- **Faces the viewer:** each player's own GPU turns the letter toward that player's eye. It's purely local, with no networking. In VR, both eyes use the point between them, so they see the same angle.
  - **Handedness:** Unity's world is left-handed but HLSL `cross()` is the plain math cross product, so the letter's right vector is `cross(facing, up)`. The other order mirrors the text (it did, until `ed8811b`; H is symmetric, so it only showed on C).
- **Visible through its own sphere:** the letter is drawn after the sphere, with its depth moved to the sphere's front surface (+2%). It shows through its own ball, but anything in front of the ball hides it.
- **`DisableBatching` tag:** required. Unity's dynamic batching would merge the letter into a world-space mesh and break the billboard.

### Material setup
- **Symbol material:** `LiberationSans SDF - Atom Symbol`. Made by duplicating `LiberationSans SDF - Outline` (the font's default material is hidden inside the font asset).
  - Symbol Color **white**, Outline Width **0**, Sphere Radius 0.5.
  - The letter's black or white comes from each TMP text's own Color.
- **TMP text:** Font Size about 4, alignment center/middle, Cast Shadows off, Material Preset = the material above.
- **Sphere material:** one per element (`Atom_H`, `Atom_C`, …), using the Atom Unlit shader.

## Bonding: `Assets/ChemistryLab/Scripts/ElementAtom.cs` (UdonSharp)

**Fields:**

| Field | Meaning |
|---|---|
| `symbol` | Element symbol |
| `maxBonds` | How many bonds the atom makes |
| `geometry` | `terminal`, `linear`, `bent`, `trigonal-planar`, `trigonal-pyramidal`, `tetrahedral`, `octahedral` or `none` |
| `bondAngle` | Angle between bonds, in degrees |
| `snapFactor` | Snap distance multiplier (default 1.6) |
| `isDispenser` | A table original: grabbing it leaves a copy in its place. Originals never bond. Ticked per scene instance (on the table's H and C), not on the prefab. |
| `deleteHoldSeconds` | How long Use must be held to delete (default 0.6 s) |

**Controls** (VRChat owns the buttons; the script reacts to the events they send). The pickup needs **Auto Hold = Yes**: ClientSim only sends Use events to Auto Hold pickups.

| Desktop | VR | Event | Result |
|---|---|---|---|
| left click | grip | `OnPickup` | grab; a dispenser leaves an `Instantiate` copy at its saved home spot |
| left click while holding | trigger tap | `OnPickupUseDown` → `OnPickupUseUp` | drop and bond |
| hold left click 0.6 s | hold trigger | `OnPickupUseDown` + `SendCustomEventDelayedSeconds` | delete the atom and everything bonded to it |
| right click | grip release | `OnDrop` not started by us | **replace** an end atom, otherwise bond |

**Replace:** a free atom dropped on an **end atom** (exactly one bond) of a molecule takes its place: it's aimed along that bond, set at r(partner) + r(new), and the old atom is destroyed. Example: C on one H of CH₄ gives H₃C–C; three more H's make ethane C₂H₆. If the end atom was the molecule's root, the new atom becomes the root.

**Sockets:** bond directions in the atom's local space, built from the geometry. Checked numerically: tetrahedral 109.471°, NH₃ pyramidal 106.67°, H₂O bent 104.478°, trigonal planar 120°. In the Editor, selecting an atom draws its sockets as **yellow gizmo lines**.

**When you let go of an atom (`OnDrop`):**
1. Find the nearest atom with a free socket within (r₁ + r₂) × 1.6.
2. Pick the **mover**: the atom not yet in a molecule. If both are free, the one with fewer bonds (so H moves onto C).
3. Choose the free socket on each atom that points most toward the other.
4. Rotate the mover so its socket faces the anchor's socket.
5. Place it at r₁ + r₂.
6. Parent it to the anchor and turn off its pickup.

**Current limits:**
- No unbonding.
- No joining two molecules.
- Replace works on end atoms only (one bond), not centre atoms.
- A bonded atom can't be grabbed separately; move the molecule by its root atom.
- Local only: remove **VRC Object Sync** from atoms for now, because synced objects can't change parent. Dispenser copies (`Instantiate`) are local too.

**ClientSim lessons (from its source, `Integrations/ClientSim/Runtime/Player/ClientSimPlayerHand.cs`):**
- **Don't destroy a held pickup inside `OnPickupUseDown`.** ClientSim calls it from its own `Update` and then keeps moving the held object (`UpdateManipulation`), causing a `NullReferenceException`. Delete from a delayed event, after `Drop()`.
- **Keeping the grab button down sends a Use** once the grab is 0.5 s old (`INITIAL_PICKUP_DURATION`). The script ignores a UseDown less than 0.6 s after the grab.
- `Drop()` calls `OnPickupUseUp` first if Use is down, so `OnPickupUseUp` must cope with being called during a drop.

### Setup in Unity (done 2026-10-15: methane works)
1. **Program asset:** `Assets/ChemistryLab/Scripts/ElementAtom.asset`. Made with Create → VRChat → Udon → **Udon C# Program Asset**, then Source Csharp Script = `ElementAtom.cs`.
2. **`Atom_H` prefab** (`Assets/ChemistryLab/Atom_H.prefab`): the Element Atom component added directly (Add Component → Element Atom), with H, 1, terminal.
3. **`Atom_C`** (`Assets/ChemistryLab/Atom_C.prefab`): a prefab variant of `Atom_H` with:
   - scale 0.152
   - material `Materials/Atom/Atom_C` (#909090)
   - Symbol text "C"
   - Element Atom: C, **4**, tetrahedral, 109.471
4. **Test:** release H atoms within about 17 cm (center to center) of the C. They snap at 10.7 cm, the real C–H length, and four of them make CH₄. ✅

### Pitfalls hit while setting up
- **Udon Behaviour → New Program makes an Udon Graph asset, not UdonSharp.** It lands in `Scenes/VRCDefaultWorldScene_UdonProgramSources/` with empty `graphData`. For UdonSharp, create the program asset from the Create menu and add the script itself as a component.
- **"Source C# script … is null" right after creating the program asset:** UdonSharp compiles as soon as the asset is created and again when it's renamed, before the script is assigned. Assign Source Csharp Script, press Compile All UdonSharp Programs, then Clear the Console.
- **Edits on a scene instance are overrides, not prefab changes.** The Carbon values were first set on the scene copy (bold fields, blue bar), so the `Atom_C` asset stayed a plain H. Fix: Overrides → **Apply All**, or edit the prefab in Prefab Mode (double-click it in the Project window).
- **Max Bonds left at 1** on the carbon: the script trims the sockets to `maxBonds`, so it would take a single H. Check for 4 yellow gizmo lines.
- **Atoms added in Play mode vanish on Stop.** Add test atoms in Edit mode (Ctrl+D). Grabbing a table atom doesn't respawn it yet; that's the dispenser step.
